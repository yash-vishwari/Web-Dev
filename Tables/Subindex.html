Description:


An HTML table is used to display data in a structured format of rows and columns .

It helps in organizing information clearly, such as timetables, marksheets, or schedules.

A table is created using the ""tag, and it contains rows (), header cells (), and data cells ().

Each row represents a horizontal set of data, while columns represent vertical data.

Special features like colspan and rowspan allow merging of columns and rows, making the table more flexible and easy to understand .
